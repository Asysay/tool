Instructions

In the following experiment we are going to show you the code changes to review.

Please take the review task very seriously (this is critical for the scientific validity of this experiment).

There is a total of two tasks with 5 files each. There is a tutorial code with two files at the start of the experiment that does not count towards the actual experiment.

Information

  • The old version of the code is on the left, the new version is on the right.
  • Review comments
    • To add a review comment, click on the corresponding line number.
    • To modify/delete a review comment, click on the corresponding line number again and modify/delete the comment's text.
  • Usage of genAI
    • At the left the screen is a window with GPT-4o. You can send both text and images to it.
    • The chat screen can be dragged left and right to increase or decrease it. Double click on the border returns it to original state.
    • GPT-4o does not have context of the experiment codebase. To get it to help on a file, please copy–paste the code into the chat window first.
  • Once you confirm to conclude the review, it will not be possible to add, delete, or modify the remarks anymore.
  • At the end of each page you will be asked to choose how much you were interrupted and how mentally taxing was the task.
